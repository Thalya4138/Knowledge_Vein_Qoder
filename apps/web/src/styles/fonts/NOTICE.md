# 字体来源与许可

| 文件 | 字体 | 许可 | 用途 |
| --- | --- | --- | --- |
| `vein-display.woff` | Noto Sans SC（子集） | SIL Open Font License 1.1 | 界面里的大号数字与西文 |
| `vein-title.woff` | 站酷小薇 ZCOOL XiaoWei（子集） | SIL Open Font License 1.1 | 大标题 |
| `vein-text.woff` | 霞鹜文楷 LXGW WenKai（子集） | SIL Open Font License 1.1（全文见 `LXGW-WenKai-OFL.txt`） | 封面、卡片、入门文档等阅读文字 |
| 字标路径 | Noto Serif SC 900、KaTeX_Main Italic | SIL Open Font License 1.1 | 「知脉」「Vein」 |

子集由 `scripts/fonts/build_fonts.py` 生成；界面文案改动后重跑。
