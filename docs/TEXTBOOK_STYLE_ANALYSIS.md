# 人教版教科书样式分析（讲义生成的范本）

**样本**：《普通高中教科书 生物学 必修 2 遗传与进化》，人民教育出版社，文字版 PDF（用户本地，不进仓库）。
**精读范围**：第 1 章（第 1、2 节、本章小结、复习与提高）；全书栏目用目录与全文检索核对。
**产出物**：`content/demo/linear-algebra/rendered` 按本分析写成，用户认可（2026-11-12）。
**执行版规则**在 `prompts/NOTE_GENERATION.md` §3.5（版式）与 §6.5（语言）。本文件是它们的证据。

> 引文只摘短句用于说明句式，页码为 PDF 页。

---

## 1. 为什么选它当范本

不是因为它是"教材"，而是因为它同时解决了 AI 讲义的三个顽疾：

| AI 讲义的病 | 教科书的解法 |
| --- | --- |
| 结论先行，概念悬空 | 先给一个**会被推翻的旧观点**，概念是被问题逼出来的 |
| 一维流，背景和主线混在一起 | **主栏 + 旁栏**：主线只放推理链，背景/史实/提问挪到旁栏 |
| 练习是附赠的题库 | 练习按"检测概念 → 拓展应用 → 思维训练"分层，干扰项瞄准具体误解 |

## 2. 栏目系统（全书统一，共 15 种）

### 节级（每节都有）

| 栏目 | 位置 | 样本中的做法 | 功能 |
| --- | --- | --- | --- |
| **问题探讨** | 节首 | 先摆出"融合遗传"观点，配一个类比（蓝墨水 + 红墨水），再问"你同意吗？你的证据有哪些？"（P11） | 立一个**将被推翻的直觉** |
| **本节聚焦** | 节首旁栏 | 3–4 个 `●` 问句，其中**必有一个是关于方法的**（"如何运用假说—演绎法进行科学探究？"） | 读完应能回答的问题 |
| **相关信息** | 旁栏 | 玉米单性花也算自交（P11）；"当时还没有认识到染色体变化……非凡的设想"（P14） | 不影响主线的背景、史实、例外 |
| **旁栏问题**（无标题） | 旁栏 | "从数学的角度分析，9∶3∶3∶1 与 3∶1 能否建立数学联系？"（P19） | **要求建立联系**，不是回忆 |
| **知识链接** | 旁栏 | "基因型能完全决定表型吗？参见本书第 4 章第 2 节。"（P22） | 前向/跨章链接，带一个问句 |
| **科学方法** | 正文框 | 先一般性描述假说—演绎法，最后问"与传统的归纳法有什么不同？"（P16） | 把例子抽成可迁移的方法 |
| **探究·实践** | 正文框 | 性状分离比模拟实验：目的要求 / 材料用具 / 方法步骤 / 结果和结论 / 讨论（P15） | 动手验证 → 对应本产品 **02 实验室** |
| **思考·讨论** | 正文框 | 山柳菊的失败 + 5 个讨论问题（P21） | 对一段史料做分析 |
| **思维训练** | 节末 | "假设你正在一个花卉生产基地工作……"，标技能名"设计实验方案"（P17） | 情境化、开放、要求设计或辨析 |
| **批判性思维** | 旁栏 | "你如何评价基因决定生物体的性状这一观点？"（P83） | 挑战一个过度简化的说法 |
| **与社会的联系** | 节末 | 吸烟与 DNA 甲基化（P83） | 应用与价值 |
| **练习与应用** | 节末 | 一、概念检测（判断 `（ ）`、单选）；二、拓展应用（真实育种情境）（P23） | 分层练习 |

### 章级

| 栏目 | 做法 |
| --- | --- |
| **本章小结** | 分两块：**理解概念**（每条是完整句："分离定律的主要内容是：……"）+ **发展素养**（能力与态度，动词开头："能够运用……""尝试……""认同……"）（P24） |
| **复习与提高** | 选择题 + 非选择题，比节末难，跨节综合（P25） |
| 科学家访谈 / 生物科学史话 / 生物科技进展 / 与生物学有关的职业 | 拓展阅读，可选 |

## 3. 语言规律（这是 AI 最学不会的部分）

### 3.1 问句 → 证据 → "看来" → 新问句

正文的推进单位不是"知识点"，是**一个问题被回答、又引出下一个问题**：

> 为什么子一代都是高茎而没有矮茎的呢？
> 孟德尔带着疑惑，用子一代自交……
> 为什么子一代没有矮茎的，而子二代又出现了矮茎的呢？
> 看来矮茎性状在子一代中只是隐而未现。（P13）

> 子二代中出现 3∶1 的性状分离比是偶然的吗？ → [表 1-1，7 对性状的数据] →
> 看来，F2 中出现 3∶1 的性状分离比不是偶然的。是什么原因……呢？（P13–14）

- 问句**单独成段**，常常一句。
- 回答它的是**证据**（实验、数据、表），不是作者的断言。
- 结论用"看来""这表明""上述分析表明""也就是说"引出——**结论被证据推出来，而不是被宣布**。

### 3.2 定义在例子之后

> 像这样，一种生物的同一种性状的不同表现类型，叫作相对性状（relative trait）。（P12）
> 像这样，遗传因子组成相同的个体叫作纯合子。（P14）

句式固定：**先有具体对象 → "像这样，……叫作 X（英文）"**。
术语加粗（排版）+ 英文括注，只在首次出现时给。

### 3.3 数据具体到个位

"1 064 株 F2 植株中，787 株是高茎，277 株是矮茎"（P13）。
不写"大量实验表明""约为 3∶1"，写**原始数字 + 编号表格**，比值保留两位小数（2.84∶1）。

### 3.4 推理连接词显式

> 因为 F1 自交的后代中出现了隐性性状，所以在 F1 的体细胞中必然含有隐性遗传因子；
> 而 F1 表现的是显性性状，因此 F1 的体细胞中的遗传因子应该是 Dd。（P14）

"因为……所以……必然""而……因此……应该"——**每一步推理都有连接词**，读者能指着说"这里用了什么前提"。

### 3.5 并列命题才编号

孟德尔的四条假说用（1）（2）（3）（4）（P14）；其余全是段落。
**编号只给真正并列、需要被逐条引用的命题。**

### 3.6 评价词克制，且只评价人和方法

出现过的评价："果断摒弃""严谨的推理和大胆的想象""超越自己所处时代的一种非凡的设想"。
全部**评价科学家的方法**，且有史实支撑。**从不评价内容本身**（没有"这非常重要""这是核心难点"）。

### 3.7 人称分工

- **主栏正文**：第三人称叙事（"孟德尔……"），偶尔"我们还可以通过模拟实验……"。
- **"你"只出现在任务里**：讨论、旁栏问题、思维训练、练习。
- 没有"你可能会想""别担心""其实很简单"这类陪聊句。

### 3.8 定律的完整写法

名称 → 别名 → 冒号后**完整陈述** → 普遍性（"在生物的遗传中具有普遍性"）→ 2–3 个其他物种例子 → 应用（育种、医学）。（P16, P21–22）

### 3.9 闭环：回到问题探讨

第 4 章正文写："'问题探讨'中水毛茛两种类型叶的形成也与环境因素相关。"（P83）
**节首立的问题，正文要明确回收。**

## 4. 内容产出规律

| 规律 | 证据 | 迁移到数学/工程课 |
| --- | --- | --- |
| 历史人物是**推理的载体**，不是装饰 | 孟德尔"带着疑惑""没有停留在观察与描述上" | 用"Legendre/Gauss 面对什么问题"推进，而不是开头一段生平 |
| 失败案例与成功同等对待 | 山柳菊为什么失败，三条原因（P21） | 一个方法**不适用**的情形，单独成段 |
| 每节至少一个"方法"抽象 | 科学方法框 | `method` 块：适用 / 步骤 / 注意 |
| 实验有完整五段结构 | 探究·实践 | 02 实验室的 `VisualizationRun` 模板 |
| 选择题干扰项瞄准具体误解 | "基因的分离发生在配子形成过程中，自由组合发生在合子形成过程中"（错误选项，P23） | 每个干扰项对应一个常见错误，答案解析说明是哪个 |
| 小结是完整句，不是关键词 | 理解概念 | `recap` 块，禁止关键词堆砌 |
| 区分"知道"与"素养" | 理解概念 vs 发展素养 | 对应 04 主动回忆的"记得结论 / 理解原因 / 能独立应用" |

## 5. 不照搬的部分

- **"与生物学有关的职业""科学家访谈"**：对大学课程价值低，默认不生成。
- **"认同……的科学精神"类素养条目**：大学讲义不写价值观条目，"发展素养"改为**能力条目**。
- **高中的确定性语气**：大学内容常有多种合理观点，保留 `viewpoint` 块，不为"像教材"而替读者定论。
- **全书统一的旁栏宽度与字号**：属于前端（`UX_AND_FLOWS` §3），不是生成器的事。
