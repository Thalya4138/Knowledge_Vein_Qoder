## 1. 全局骨架

```text
┌───────────────────────────────────────────────────────────────┐
│ Cognitive Atlas    [当前：线性代数 ▾]     搜索⌘K   保存状态  设置 │
├──────────┬──────────────────────────────────────┬─────────────┤
│ 学习工作台 │                                      │             │
│ 可视化实验室│            主区（随板块变化）          │  AI 侧栏     │
│ 知识关联探索│                                      │ （可收起）   │
│ 认知与记忆图谱│                                    │ 上下文来自选区│
├──────────┴──────────────────────────────────────┴─────────────┤
│ 状态条：离线可用 · 数据存于本机 · 未配置 API（示例模式）          │
└───────────────────────────────────────────────────────────────┘
```

**要点**：
- 左侧是四个视口，**不是四个 app**。切换不丢上下文（同一选中节点可跨板块跟随）。
- AI 侧栏是**侧栏**，不是一级页面。它读取"当前选区"，不是"当前路由"。
- 状态条常驻，明确告诉用户：数据在哪、现在是不是示例模式。**这两条是信任的基础。**

## 2. 四条主路径（每条 ≤5 步）

### 路径 A · 资源 → 可读讲义

```
① 新建/打开知识库 → ② 导入资源（拖入 PDF/粘贴文本/勾选系统发现的资源）
→ ③ 生成讲义（显示来源覆盖与空白处） → ④ 读 + 展开折叠例题
→ ⑤ 编辑 → 预览 diff → 保存 → 导出 .md + .json
```

**失败样例**：生成完直接落盘、无 diff、用户不知道哪句是哪来的。

### 路径 B · 问题式学习

```
① 输入问题 → ② 看到「命中位置列表」（文档·锚点·片段·上下文差异）
→ ③ 点开某一处，跳到原文 → ④ 读解释（定位之上） → ⑤ 一键补入（预览 diff）
```

**顺序不可颠倒**：先位置，后解释。

### 路径 C · 关联探索

```
① 甩入 2–4 个概念/题型 → ② 看对应表与统一句 → ③ 看差异与反例
→ ④ 追问 / 请求可视化 → ⑤ 存为候选边 或 生成报告
```

### 路径 D · 个人记忆

```
① 切到个人记忆视图 → ② 拖动节点 / 手绘连线 / 分组
→ ③ 侧栏问 AI（得到建议，不自动应用） → ④ 主动回忆（隐藏关系重建）
→ ⑤ 撤销/重做，或导出
```

## 3. 阅读器规格（这是产品的门面）

- **行宽 42–50 em**，正文 17–18px，行高 1.7。宽屏下左右留白，不用两栏正文。
- **正文衬线，UI 无衬线**。中文衬线优先 `Noto Serif SC` / `Source Han Serif`。
- **标题层级靠字号与留白**，不靠彩色横条。
- **语义块有稳定视觉**：

| 块 | 视觉 |
| --- | --- |
| `source_quote` | 左侧竖线 + 稍小字号 + 右下角来源定位 |
| `definition` / `theorem` | 细边框块，标签在左上，**不折叠** |
| `caveat` / `correction` | 浅底 + 图标（⚠/✎），文字仍为正文色 |
| `viewpoint` | 多项并列，缩进层级，**不选边** |
| `method` | 三行结构：适用 / 步骤 / 注意 |
| `extension` | 灰化 + 明确标"拓展" |
| `<details>` | 单行摘要 + 三角，展开后与正文同宽 |

- **锚点可复制**：悬停标题出现 `§`，点击复制 `笔记#锚点`。
- **搜索高亮**在正文内，`n/N` 跳下一个。

## 4. 图谱规格

### 通用
- 区分 **节点大小 = importance**（core 大、extension 小且半透明），不要所有点一样大。
- 边样式由 `epistemic` 决定（见 `layouts/logic.json` 的 `edgeStyle`），
  **颜色 + 线型 + 文字标签三重区分**（色盲可达）。
- 点边→右侧显示：类型、explanation、assumptions、boundary、来源锚点、"这条边我不同意"。
- **空状态给动作**："还没有关系。从关联探索带一条过来，或手动连一条。"

### 三视图切换
- 顶部 tab；切换**保留缩放与选中节点**。
- 同一节点在三视图里视觉上"是同一个东西"：同色圆形 + 同标题。

### 个人记忆视图（重点）
- 拖拽即时保存（节流 300ms），显示"已保存"。
- 手绘连线：从一个节点拖到另一个，弹出输入框填"这条线对我意味着什么"。
- 分组：框选 → 右键 → 建组 / 加组 / 编号排序。
- 副作用提示：任何 AI 建议以**半透明幽灵层**叠加显示，点"应用"才实体化。
- **不允许**：AI 静默移动、自动布局覆盖用户位置、切换视图导致布局重排。

## 5. AI 侧栏

- 宽 320–400px，可收起为 48px 竖条。
- 顶部显示**当前上下文**（"选中：法方程 · 1 条关系"），可点 × 清除。
- 回答分两段：**先结论**，再"依据 / 展开"。
- 任何写操作显示 **diff 卡片**：`+ 新增 3 行 / 影响 2 个节点`，按钮：应用 / 修改 / 拒绝。
- 拒绝时弹一句"为什么不要？"（可选填），用于改进建议质量。
- 失败时保留用户已输入内容，给重试与"以示例模式继续"。

## 6. 视觉系统

**气质**：学术阅读 + 精密仪器。不是 SaaS 后台，不是 AI 玩具。

| 项 | 选择 |
| --- | --- |
| 主色 | 深墨蓝 `#1f3a5f`（链接、强调） |
| 中性 | 纸白 `#fbfaf7` 背景，`#1a1a1a` 文字，`#6b6b6b` 次要 |
| 语义色 | 证据=蓝 / 推导=青绿 / 教学推论=琥珀 / 类比=紫 / 猜想=灰 / 个人=品红 |
| 圆角 | 4px（块）/ 2px（边）——克制，不要大圆角卡片 |
| 阴影 | 几乎不用；靠边框与留白分层 |
| 动效 | 仅用于状态变化（保存、展开），150ms，尊重 `prefers-reduced-motion` |

**明令禁止**：满屏浅灰小字、无边框的浮动导航、装饰性 emoji、渐变光晕、
每个区块都套圆角卡片、"✨ AI 生成"之类的徽标滥用。

## 7. 响应式

| 宽度 | 布局 |
| --- | --- |
| ≥1280 | 三栏（导航 + 主区 + AI） |
| 768–1279 | 两栏，AI 变抽屉 |
| <768 | 单栏；图谱降级为**列表模式**（节点 → 它的关系），阅读优先 |

手机端**不要求**完整图谱编辑。要求：能读、能搜、能看关联结论、能做轻编辑。

## 9. 无障碍

- 键盘可达全流程；焦点环 2px 可见。
- 关系不只用颜色区分（线型 + 文字）。
- 对比度 ≥4.5:1。
- 图谱提供键盘导航（Tab 遍历节点，Enter 打开详情）。
