# 信息架构、用户路径与交互设计

## 1. 网站导航（桌面优先，移动端可使用）

顶部/左侧四个一级区：
1. 学习工作台（课程/专题/资源/讲义/搜索）
2. 可视化实验室（实验/工具/参数/结果）
3. 知识关联探索（A 联系发现/B 学科元结构/C 跨学科）
4. 认知与记忆图谱（结构/逻辑/个人记忆）

共有：顶部全局搜索、当前工作区/课程、保存状态、快捷命令入口；右侧**可收起的上下文 AI 助手**，选区/节点/关系/图形作为上下文，支持“解释、可视化、找联系、生成补充、保存候选”。不是四个孤立聊天机器人。

## 2. 主要用户路径

### 路径一：资源 → 真正可读的讲义
- 新建“线性代数”课程，导入公开许可示例笔记；系统列出用户给定资源和主动检索建议，用户勾选可信资源。
- 展示课程目录、源材料和讲义；生成草案时显示引用状态，空白来源不能伪装引用。
- Markdown 阅读与编辑双模式；自然正文中嵌入定义/材料/辨析卡、公式、可折叠例题、资源 link。阅读时**不会默认展开所有练习**。
- 修改草案 → 预览 diff → 用户确认 → 本地保存 → 图谱索引更新 → Markdown/ZIP 导出。
- 原资源可侧栏随时查阅，不压缩成唯一“AI 总结”。

### 路径二：问题式学习
- 输入“Gram 矩阵为什么在这两题出现？”
- 优先跨当前讲义搜索并列出标题、定位路径、相关段落；可打开源/笔记对应位置。
- AI 解释为何这些位置有关、缺哪些先修；给小规模交互实验或证明；必要时可联网，但分开显示外部来源。
- 点击“作为补充写入笔记”，选择位置 → 预览差异 → 确认；不覆盖个人正文。

### 路径三：关联探索
- 粘贴“点到平面最短距离、异面直线距离、最小二乘”进入 A 模式。
- 输出“共同问题—具体映射—条件—相同/不同—反例”的可追问内容。
- 支持“只解释 / 展示 UI / 保存关系候选 / 生成专题报告”四种输出。
- 生成的候选图边可逐条接受/拒绝，拒绝原因保存供未来建议改进。

### 路径四：个人记忆
- 切换结构、逻辑、个人记忆视图，各自保存布局；支持节点拖动、框选、聚合、手工连线、选择类型、编辑层级/顺序、键盘操作、撤销/重做。
- 个人记忆图可创建自由关联路径；侧栏 AI 只能提出建议，不自动整理掉用户的空间记忆。
- 复习时隐藏部分关系让用户自己重建；结果写入 LearningEvidence，不靠阅读次数宣布“已掌握”。

## 3. 编辑器与可视化要点

- 阅读器：目录可折叠、主文有舒适行宽、材料与辨析用稳定标识；数学公式正常渲染、代码高亮；可双击或快捷键编辑段落。
- 图谱：区分强证据、推论、类比、个人联想；连线编辑时填写关系类型、自然语言解释和依据。允许无连线节点，不自动捏造关系。
- 侧栏布局：视图切换不丢定位/缩放；大图不会遮挡文字；提供节点搜索与局部焦点模式。
- AI 变更：用批注/差异预览体现写入位置、影响节点数与可撤销性。
- 设计风格：学术阅读质感和高对比信息层次，蓝/银/中性色为主，避免一屏冷淡小字、无边框淡导航、装饰性符文和无意义悬浮气泡。交互简洁但有反馈，动画服务理解。
- 手机端优先阅读/查询/轻编辑；复杂图谱可切换列表模式，桌面编辑更完整。
- 无障碍：键盘可达、焦点可见、对比足够、颜色以外还有关系文字/形状、尊重减少动画偏好。

## 4. 首页与 Demo 推荐

不以四张“功能介绍卡”代替可用产品；直接提供“进入示例线代课程”“导入资料”“探索两个概念的关系”。评委 30 秒内可看到已完成的核心功能。

推荐演示路径（5 步内）：
1. 打开示例“线性代数：最小二乘”。
2. 看可读讲义并展开一个例题；搜索“法方程”跳转具体段落。
3. 打开投影实验，拖动向量，观察正交条件。
4. 在关联探索提出“最小二乘与异面直线距离”的联系，查看依据与边界。
5. 接受/编辑一条候选关系，切换个人记忆图谱并导出工作区。
