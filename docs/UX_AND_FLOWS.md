# 界面、流程与视觉

**本文件只管"长什么样、怎么走"。产品定义看 [PRODUCT_SPEC.md](PRODUCT_SPEC.md)，不要在这里重述。**

---

## 0. 一个网页 = 整个平台

**不是四个 app，不是桌面端 + 网页端。就是一个网页。**
四个板块是它的四个工作区，切换不换站点、不丢状态。

知识库的粒度由用户开库时决定，UI 只换导航的深度，不换结构：

| `level` | 左侧导航显示 | 例 |
| --- | --- | --- |
| `discipline` | 学科 → 其下课程 → 章节 | 数学 → 线性代数 / 数学分析 / 概率论 |
| `course` | 课程 → 章节 | 线性代数 → 列空间 / 法方程 / 三种最近 |
| `topic` | 专题 → 若干节 | 凸优化入门 → 凸集 / 一阶条件 |

P0 只演示 `course` 一种。`discipline` 不需要额外功能——同一份 schema，
多了 `childKbIds` 而已。**不要为它单独开发一套导航。**

## 1. 全局骨架

```text
┌───────────────────────────────────────────────────────────────┐
│ 知脉 Vein          [当前：线性代数 ▾]     搜索⌘K   保存状态  设置 │
├──────────┬──────────────────────────────────────┬─────────────┤
│ 学习工作台 │                                      │             │
│ 可视化实验室│            主区（随板块变化）          │  AI 侧栏     │
│ 知识关联探索│                                      │ （可收起）   │
│ 认知与记忆图谱│                                    │ 上下文来自选区│
├──────────┴──────────────────────────────────────┴─────────────┤
│ 状态条：离线可用 · 数据存于本机 · 未配置 API（示例模式）          │
└───────────────────────────────────────────────────────────────┘
```

**学习工作台内部的二级导航**（不是新增一级板块）：

```text
学习工作台
├── 讲义     读 / 编辑（默认）
├── 资源库   我有什么、用了没、哪节没有来源   ← 独立页面，不是讲义末尾的链接列表
├── 检索     问题式学习的入口
└── 报告     生成过的论证报告（随知识库落盘在 reports/）
```

**要点**：
- 左侧是四个视口，**不是四个 app**。切换不丢上下文（同一选中节点可跨板块跟随）。
- AI 侧栏是**侧栏**，不是一级页面。它读取"当前选区"，不是"当前路由"。
- 状态条常驻，明确告诉用户：数据在哪、现在是不是示例模式。**这两条是信任的基础。**

## 2. 四条主路径（每条 ≤5 步）

### 路径 A · 资源 → 可读讲义

```
① 新建/打开知识库 → ② 导入资源（拖入 PDF/粘贴文本/勾选系统发现的资源）
→ ③ 生成讲义（显示来源覆盖与空白处） → ④ 读 + 展开折叠例题
→ ⑤ 编辑 → 预览 diff → 保存 → 导出 .md + .json
```

**失败样例**：生成完直接落盘、无 diff、用户不知道哪句是哪来的。

### 路径 B · 问题式学习

```
① 输入问题 → ② 看到「命中位置列表」（文档·锚点·片段·上下文差异）
→ ③ 点开某一处，跳到原文 → ④ 读解释（定位之上） → ⑤ 一键补入（预览 diff）
```

**顺序不可颠倒**：先位置，后解释。

### 路径 C · 关联探索

```
① 甩入 2–4 个概念/题型 → ② 看对应表与统一句 → ③ 看差异与反例
→ ④ 追问 / 请求可视化 → ⑤ 存为候选边 或 生成报告
```

### 路径 D · 个人记忆

```
① 切到个人记忆视图 → ② 拖动节点 / 手绘连线 / 分组
→ ③ 侧栏问 AI（得到建议，不自动应用） → ④ 主动回忆（隐藏关系重建）
→ ⑤ 撤销/重做，或导出
```

## 3. 阅读器规格（这是产品的门面）

> **视觉验收样张：[`content/demo/linear-algebra/rendered/index.html`](../content/demo/linear-algebra/rendered/index.html)**（2026-11-12 用户认可）。
> 本节与样张冲突时**以样张为准**，并回来改本节。

- **版式 = 主栏 + 旁栏（二维）**，参照人教版教科书：主栏是连续叙述；旁栏与它**逐段对齐**，
  放资源片段（视频时间戳 / PDF 页 / 网页文本锚）、图、术语、"为什么链到这里"。
  点击旁栏资源 → **左侧**抽屉显示**原文引文 + 精确位置 + 一句理由**，不是跳到资源主页
  （两层交互的完整规格见下文"资源抽屉"，决策见 ADR-0007）。
  窄屏（<1100px）旁栏退化为主栏内联卡片。
  （旧规定"宽屏不用两栏正文"已废止——它产出的是一维流，用户否决过。）
- **主栏行宽 42–50 em**，正文 17–18px，行高 1.7。
- **正文衬线，UI 无衬线**。中文衬线优先 `Noto Serif SC` / `Source Han Serif`。
- **标题层级靠字号与留白**，不靠彩色横条。
- **语义块有稳定视觉**（参照积木笔记 + 人教版高中生物书的旁栏）：

| 块 | 视觉 | 交互 |
| --- | --- | --- |
| `material` | 细边框圆角盒（1px，圆角 4px），**标题压在上边框上**（fieldset legend 式，白底小标签），出处右对齐在盒内底部 | 无；长材料可"在新面板打开原文" |
| `note` | 左侧 2px 竖线，字号 0.9em，颜色略淡，无边框 | 悬停显示"术语卡" |
| `aside` | 左侧 2px 竖线，正文大小，标题加粗 | 可折叠（默认展开） |
| **`link`** | **便签卡**：浮起（轻阴影），左上角有一个小折角，头部显示目标知识点名 + 一个"↗"跳转箭头 | **点击卡片展开/收起**；展开后是完整的三段式（是什么/为什么在这里/在别处）；"↗"跳到目标节点 |
| `trap` | 浅暖色底（#fdf8f0）+ 左侧 3px 琥珀色边，标题带 ⚠ | 无 |
| `exercise` | 编号卡片，题干在上，答案 `<details>` 默认折叠 | 折叠展开；可"标记已做" |
| `method` | 三行结构：适用 / 步骤 / 注意，行首有小标签 | 无 |
| `viewpoint` | 多项并列，缩进层级，**不选边** | 无 |
| `unsourced` | 极淡底纹 + 右上角小角标"原创论述" | 无 |
| `<details>` | 单行摘要 + 三角，展开后与正文同宽 | 键盘可展开 |

**`link` 便签的位置**：窄屏时**内联**在正文里（像生物书的旁栏）；宽屏（≥1100px）
时可选择"旁挂"到右侧空白区，与正文段落对齐——这是它区别于普通引用的关键。

### 资源抽屉（两层：先在抽屉里看，再从抽屉去详情）

行为基准是样张的 `content/demo/linear-algebra/rendered/app.js`；验收项见 `QUALITY_GATES.md` §2.5。

**第一层：抽屉内直接看片段，不离开讲义。**

- 点旁栏资源卡（或窄屏下的内联卡片）→ 从**左侧**滑出抽屉，覆盖左导航与旁栏区域；
  主栏的路由与滚动位置不变。左侧是因为资源卡本身就在主栏左侧的旁栏里——从哪里点，就在哪里展开。
- 抽屉固定显示五项，全部从 `resources/manifest.json` 的 span 读取，组件里不写死任何资源内容：
  类型标签 · 标题与许可 · **定位**（时间段 / 页码 / 文本锚）· **原文片段**（关键句高亮，视频带逐句时间戳）·
  **为什么链到这里**（span 的 `why`）。
- 按资源类型决定"在抽屉里能看到什么"：

| 类型 | 抽屉内 | 不做 |
| --- | --- | --- |
| PDF | 引文 + **内嵌预览，定位到对应页**（`#page=N&view=FitH`） | — |
| 视频 | 引文（逐句时间戳）| **不内嵌播放器**：负荷大，且部分视频站在评委网络环境下加载不出，会留下空白框 |
| 网页 | 引文 | 不内嵌 iframe：多数站点禁止被嵌入 |

**第二层：从抽屉去详情。** 抽屉底部是按类型生成的深链按钮，新标签打开：

| 类型 | 主按钮 | 次按钮 |
| --- | --- | --- |
| 视频 | "从 mm:ss 开始播放"（URL 带起始时间） | 课程页（字幕下载） |
| PDF | "打开第 N 页"（本地副本 `#page=N`） | 在线原文（同样带 `#page=N`） |
| 网页 | "打开并高亮这句话"（`#:~:text=` 文本片段） | — |

- 定位不可用（`locator.type = "unavailable"`）时，抽屉显示"位置待核对"，**不得退化成只到资源主页的链接**。

**关闭与可达性**：× 按钮、点遮罩、`Esc` 均可关闭；打开时焦点移入抽屉，关闭后焦点回到被点的那张卡片；
打开另一张卡片时直接替换抽屉内容，不叠第二层。`?open=<spanId>` 直接打开某条资源（用于截图验收与分享）。

**与 AI 侧栏的关系**：二者**分居两侧**——资源抽屉在左，AI 侧栏在右（§5），可以同时打开、互不遮挡。
窄屏放不下两侧时，后打开的一方覆盖先打开的一方，关闭后恢复。

- **锚点可复制**：悬停标题出现 `§`，点击复制 `笔记#锚点`。
- **搜索高亮**在正文内，`n/N` 跳下一个。
- **正文宽度与块宽度不同**：正文 42–50 em；`material` 块可略微出血（+2em），
  视觉上"展开"，表明这是引来的外部内容，不是作者自己的话。这个宽度差本身就是语义。

## 4. 图谱规格

### 通用
- 区分 **节点大小 = importance**（core 大、extension 小且半透明），不要所有点一样大。
- 边样式由 `epistemic` 决定（见 `layouts/logic.json` 的 `edgeStyle`），
  **颜色 + 线型 + 文字标签三重区分**（色盲可达）。
- 点边→右侧显示：类型、explanation、assumptions、boundary、来源锚点、"这条边我不同意"。
- **空状态给动作**："还没有关系。从关联探索带一条过来，或手动连一条。"

### 三视图切换
- 顶部 tab；切换**保留缩放与选中节点**。
- 同一节点在三视图里视觉上"是同一个东西"：同色圆形 + 同标题。

### 个人记忆视图（重点）
- 拖拽即时保存（节流 300ms），显示"已保存"。
- 手绘连线（`PersonalEdge`，ADR-0006）：从一个节点拖到另一个，弹出输入框填**可见标签**（必填，
  就是线上那句话）与「这条线对我意味着什么」（选填）。理由可以不写，但下面两条必须守住，
  否则"图谱的边都有理由"这个卖点就站不住：
  1. **看得出区别**：画成虚线 + 「我的联想」标签，与 `KnowledgeRelation` 一眼可分，
     不用同一种线型再加个颜色了事。
  2. **只待在个人视图**：不渲染进逻辑视图与结构视图，报告也不得引为论据——
     不写理由的边只影响你怎么记，不冒充数学结论。
  设置页可加「画边时要求写理由」开关（默认关）；那是自我约束工具，不改变上面的规则。
- 分组：框选 → 右键 → 建组 / 加组 / 编号排序。
- 副作用提示：任何 AI 建议以**半透明幽灵层**叠加显示，点"应用"才实体化。
- **不允许**：AI 静默移动、自动布局覆盖用户位置、切换视图导致布局重排。

## 5. AI 侧栏

- 宽 320–400px，可收起为 48px 竖条。
- 顶部显示**当前上下文**（"选中：法方程 · 1 条关系"），可点 × 清除。
- 回答分两段：**先结论**，再"依据 / 展开"。
- 任何写操作显示 **diff 卡片**：`+ 新增 3 行 / 影响 2 个节点`，按钮：应用 / 修改 / 拒绝。
- 拒绝时弹一句"为什么不要？"（可选填），用于改进建议质量。
- 失败时保留用户已输入内容，给重试与"以示例模式继续"。

## 6. 视觉系统

**气质**：学术阅读 + 精密仪器。不是 SaaS 后台，不是 AI 玩具。

| 项 | 选择 |
| --- | --- |
| 主色 | 深墨蓝 `#1f3a5f`（链接、强调） |
| 中性 | 纸白 `#fbfaf7` 背景，`#1a1a1a` 文字，`#6b6b6b` 次要 |
| 语义色 | 证据=蓝 / 推导=青绿 / 教学推论=琥珀 / 类比=紫 / 猜想=灰 / 个人=品红 |
| 圆角 | 4px（块）/ 2px（边）——克制，不要大圆角卡片 |
| 阴影 | 几乎不用；靠边框与留白分层 |
| 动效 | 仅用于状态变化（保存、展开），150ms，尊重 `prefers-reduced-motion` |

**明令禁止**：满屏浅灰小字、无边框的浮动导航、装饰性 emoji、渐变光晕、
每个区块都套圆角卡片、"✨ AI 生成"之类的徽标滥用。

## 7. 响应式

| 宽度 | 布局 |
| --- | --- |
| ≥1280 | 三栏（导航 + 主区 + AI）；资源抽屉从左侧覆盖导航与旁栏 |
| 768–1279 | 两栏，AI 变右侧抽屉；资源抽屉仍在左侧，两者可同时打开 |
| <768 | 单栏；图谱降级为**列表模式**（节点 → 它的关系），阅读优先；资源抽屉全屏打开，后开的覆盖先开的 |

手机端**不要求**完整图谱编辑。要求：能读、能搜、能看关联结论、能做轻编辑。

## 8. 首页（评委 30 秒判断的地方）

**不要**四张功能卡片。直接给三个动作：

```
┌─────────────────────────────────────────────────────────┐
│  知脉 Vein                                              │
│  已经学过的东西，怎样才能真正连起来？                      │
│                                                         │
│  [ 打开示例课程：最小二乘 ]  [ 导入我的资料 ]  [ 探索两个概念 ] │
│                                                         │
│  示例包含：{讲义节数} 节讲义 · {节点数} 个知识节点                 │
│              · {关系数} 条带理由的关系 · {实验数} 个实验          │
└─────────────────────────────────────────────────────────┘
```

下面直接放**真实可交互的讲义第一屏**，不是截图。

**这四个数字必须运行时从已加载的数据算出来，不准写死。** 本文件此前手写的是
「3 节讲义 · 9 节点 · 9 关系 · 1 实验」；`content/demo` 扩到 15 节点 / 13 关系 /
1 篇成稿讲义 / 0 实验后，那句话就成了评委打开就能拆穿的谎。
统计口径：讲义节数 = `kb.json` 里 `status: "written"` 的条目数；关系数只算
`status: "accepted"`；实验数 = 已注册且 `status: 'real'` 可用的工具数——没有就写 0，
不要用计划中的功能凑数。

## 9. 无障碍

- 键盘可达全流程；焦点环 2px 可见。
- 关系不只用颜色区分（线型 + 文字）。
- 对比度 ≥4.5:1。
- 图谱提供键盘导航（Tab 遍历节点，Enter 打开详情）。
