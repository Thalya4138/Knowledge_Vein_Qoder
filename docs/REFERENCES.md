# 参照产品与页面

2026-11-12 用 curl 实际抓取首页/项目页（带浏览器 UA）。**下表「它做什么」只写页面上看得到的事实**；
「借什么 / 不借什么」是我们的判断。页面会变，引用前重新核对。

> 区分：用户说的「学校团队做的笔记 AI」样本是 **notebrick**（见 `NOTE_SAMPLE_ANALYSIS.md`），
> 不是下表的 notasand。两者名字像，别混。

---

## 1. 逐个看

### notasand — <https://www.notasand.com/>
- **它做什么**：上传 PDF → 用户高亮段落 → **用自己的话解释** → AI 校验理解、指出漏掉的概念，
  在页边生成个性化 Markdown 笔记。
- **借**：「先让人说，再让 AI 评」这个顺序。它就是 04-C 主动回忆 / 理解验证的最小形态。
- **不借**：它以单个 PDF 为边界，没有跨文档结构，笔记是批注不是讲义。

### Thinki — <https://www.thinki.io/>
- **它做什么**（只拿到 meta 描述，正文是 JS 应用）：PDF、笔记、写作、AI 助手合在一个工作区，
  自称 "like Cursor, but for researchers"。
- **借**：「AI 嵌在工作区里，围绕选区工作」——对应 `PRODUCT_SPEC` §7.1，AI 不独占一级页面。
- **不借**：面向科研写作，不处理课程结构与记忆。

### 3Blue1Brown · Change of basis — <https://www.3blue1brown.com/lessons/change-of-basis/>
- **它做什么**：视频课的**文字改编版**。开头一句 Poincaré 题记，从一个具体向量 (3,2) 出发，
  先问"这两个数到底是什么意思"，再引出基向量与坐标系；正文是连续散文，中间嵌动画。
- **借**：叙事从**一个具体对象和一个问题**开始，概念是被问题逼出来的——这正是讲义的第一原理。
  也是 02 实验「嵌在讲义段落里」而不是独立页面的范例。
- **不借**：单作者精雕，不可规模化；没有来源对账、没有练习分层。

### Calculus Playground — <https://calculus.berrry.app/>
- **它做什么**：单页小应用。选函数（x²、sin x…）、设求值点 x 和步长 h，
  画原函数与导数，并**把差商的每一步数值算给你看**（f(2.1)=4.41, f(2)=4, (4.41−4)/0.1=4.1）。
- **借**：实验不必宏大——**一个参数 + 暴露中间计算**就够。T5 正交投影实验照这个尺度做。
- **不借**：和任何讲义、知识结构都不连，是孤立玩具。我们的实验必须回链讲义锚点。

### TensorX / TensorReading — <https://www.tensorx.xin/>
- **它做什么**：AI 文献阅读与管理桌面工具（Win/macOS/浏览器插件）；
  功能标签为"知识图谱 · AI 大纲 · AI 对话 · 划词翻译"，按订阅主题推荐论文。
- **借**：划词即问的低摩擦交互。
- **不借**：对象是论文不是课程；"知识图谱"在首页只是功能名，看不出边是否带理由。

### WiseGraph — <https://wisegraph.app/students>
- **它做什么**：上传章节 → 生成**由小主题组成的可视化地图**，每个节点是 5 分钟微课
  （笔记 + 闪卡 + 测验）；按间隔重复与交错练习排学习计划；可协作编辑笔记与闪卡。
- **借**：节点是**学习入口**而不只是标签；复习排程。
- **对立点**（我们的判断）：从首页看，图是"按主题切块"的目录，节点之间的连线没有展示理由与条件。
  这正是本项目反对的"自动生成思维导图"形态——**评委若熟悉它，帖子里要正面说清差别**。

### ClassPulse（Devpost 黑客松项目）— <https://devpost.com/software/classpulse-8ew9gj>
- **它做什么**：把 Google Meet 答疑转写稿变成语义图，**把学生的表面问题（症状）追溯到缺失的基础概念（病根）**，
  给助教看。栈：Next.js + FastAPI + Gemini 抽取概念与关系 + Neo4j。
- **借**：
  1. **"症状 → 病根"** 正是 01 问题式学习里"你还缺哪些先修"的那一步，表述可以借。
  2. 它自述的难点——**LLM 产出的节点和边"太泛"**——和我们要防的失败完全一致，
     是"边必须带理由"这条约束的外部佐证。
  3. **帖子结构**：Inspiration / What it does / How we built it / Challenges / Accomplishments /
     What we learned / What's next。天池帖可照此组织（见 `CONTEST_SUBMISSION.md`）。
- **不借**：面向教师端；图由模型全自动生成，学习者不能编辑。

这是我们的位置；但**没搜到 ≠ 不存在**，帖子里不写"首创"。
