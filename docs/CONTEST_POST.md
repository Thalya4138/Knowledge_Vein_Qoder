## 2. 一句话作品

知脉把一门课的资料整理成像教科书一样能读的讲义，再把讲义里的知识连成一张**每条线都有理由**的网——这张网由你逐条确认、可以自己编辑，也能拿来考自己。

## 3. 为什么做

【待本人填写】写你自己真实卡住过的地方，不写行业趋势。下面是产品里每个设计对应的问题，可以从中挑你真正经历过的，换成你的话和具体例子：

- AI 生成的思维导图节点很多，但线没有理由：看不出两个知识点凭什么相连、在什么条件下成立，所以既不能用来回忆，也不能用来迁移。→ 知脉的每条知识关系都必须写明理由、成立条件和认知状态（有出处 / 可推导 / 教学归纳 / 类比 / 猜想），由你确认后才进图谱。
- AI 讲义读起来顺，合上就忘：它是一篇提纲，没有接在课本和原始资料上。→ 讲义照人教版教科书的版式写，旁栏资源卡指向原视频的具体时刻、原文档的具体页。
- 学完一章，题目换个问法就不会：不知道几个看起来不同的问题其实是同一个结构。→ 关联探索的「碎片串联」把零散的题和方法放在一起，自下而上找出共同结构，再落实到你能自己动手验证的地方。

## 4. 怎么用（五步，配截图）

在线地址打开即可，不需要注册，也不需要 API key。第一次来可以点封面的「跟着导览走一遍」，约五分钟。

```text
① 学习工作台：打开示例课程「线性代数」的《正交投影与最小二乘法》，主栏正文、旁栏资源卡
② 问一个问题：底部对话框选「法方程是怎么推出来的？」→ 点回答里的出处，讲义跳到那一段并高亮
③ 标题旁「在导图里看」→ 认知记忆图谱选中同一个知识点；右栏「打开讲义对应处」再跳回来
④ 关联探索：点示例「最小二乘、点到平面的距离、异面直线的距离，是同一个问题吗？」
   → 关联图上点一条线，看它的理由与成立条件 → 点「收进图谱」
⑤ 个人记忆图谱：挖空叶子，填完按 O 对照原文
```

截图对应 `docs/evidence/`：`tour-cover-1440.png`、`tour-golink-1440.png`、`linkage-atlas-1440.png`、`tour-cxgraph-1440.png`、`tour-memory-1440.png`。发布前在线上站重拍一遍。

## 5. Qoder 开发过程

【待本人确认】这一段决定「Qoder 使用深度」得分，只写真实发生过、且确实在 Qoder 里完成的事，并配开发对话截图。下面是开发日志里有据可查的过程素材（出处在 `docs/DEVELOPMENT_LOG.md` 与 `docs/HANDOFF.md` 接龙表），请按实际情况取舍：

- **先写契约，后写代码。** 开工前把「每条关系必须有理由」写进 JSON Schema 和内容校验脚本，生成的数据过不了校验就进不了仓库。开发中校验脚本抓到过一个指向不存在标题的讲义锚点，修的是数据，没有放宽规则。
- **多角色协作。** 实现与审查分开：实现者认领任务、开分支、交付；审查者复验、给裁决建议。协作只通过仓库里的交接卡（接龙表，已到六十多条），不依赖聊天记录。
- **部署到 Qoder Sites 时踩过的坑**：
  - 用脚本测深链回退，第一次得到 404，差点据此放弃浏览器路由。查下去发现托管站只对页面导航做单页回退，资源请求不回退；改用真正的页面导航实测后，深链可用（ADR-0002）。
  - 发现 Sites 从本地构建产物打包、不从 git 构建：本地一次构建就会改变「将要发布的内容」。此后每次发布前先核对构建产物里有没有未提交的改动。
  - 托管站对不存在的文件也回 200 + 首页 HTML，程序把这页 HTML 当成导图数据读，报错。单元测试抓不到，浏览器验收抓到；修法是非 .html 路径收到 HTML 就当作文件不存在。
- **用户反馈驱动的返工**：关联探索被否过多轮（「把核对机制当内容给读者看」「三种模式共用一个模板」），每一轮的否决理由与改法都记在日志里。
- **每轮的验证方式**：类型检查、单元测试、内容校验、构建四道门，加无头浏览器验收脚本（导览 22 站逐站走、四板块联动、实验室版式），截图存在 `docs/evidence/`。

## 8. 技术与限制

- **没有 API key 时**：讲义阅读与编辑、批注、出处定位、四个板块之间的跳转、三张示例实验页、思维导图编辑、记忆图谱自测、关系的收进与撤回，全部是真实功能。生成类功能（问答、关联探索、生成实验页、按讲义生成导图）只回答预置问题，界面上标着「示例」，答案是离线整理、人工核对过的。
- **接入自己的模型**：知脉没有服务器，浏览器直接调用模型服务。DeepSeek、通义千问、Kimi、硅基流动、OpenRouter 已实测允许浏览器直连；key 默认只存在当前标签页，关掉即清除；也可以选择在自己的电脑上记住。
- **可视化实验室接入模型后**：现场生成能动手的页面，在隔离沙箱里运行（读不到 key 和工作区），跑不起来自动修一次。GeoGebra、Plotly、Three.js、Matplotlib（浏览器里的 Python）等 8 个库在沙箱里实测能加载；Manim、MATLAB 这类只能本地跑的给可运行代码；要第三方授权的（Desmos 等）换成能用的工具并写明原因。
- **数据在哪里**：工作区就是一个文件夹。Chrome / Edge 可以直接读写电脑上的文件夹，和 Obsidian 共用；其他浏览器可以把文件夹导入浏览器。浏览器工作区还能与一个 GitHub 仓库双向同步，两边都改过的文件逐个选，不自动合并。
- **界面语言**：中文与英文。英文覆盖外壳与四个板块的入口，示例课程内容仍为中文。
- **尚未实现**：浏览器工作区直接导出为本地文件夹、语义检索、在站内运行 MATLAB / PyTorch。
