# 技术与产品决策记录

## ADR-0001（2026-11-11）：网站优先、文件优先、用户控制

**状态**：提议，待 Qoder 技术验证。

背景：用户希望网页能阅读、编辑与浏览图谱，同时长期可以在本地工作区落盘并用 Git 管理。公开静态/Serverless 网站并不天然有用户电脑任意文件读写权限。

选择：
- 首版浏览器内 IndexedDB 保存工作副本，Markdown+JSON 导入导出；
- 三图谱视图共用知识实体但保留独立布局；
- 通过用户确认接纳 AI 讲义修改和关联边；
- 需要本地 Git 双向同步时再建立用户授权的 File System Access 或本地 companion；
- Qoder Sites 仅承担比赛公网演示，真实可用能力需验证后再写代码。

取舍：首版不是完整本地 Git 同步器，也不是任意工具执行平台；获得更可靠的独立网页演示、离线数据保护与用户控制。待验证的问题：Qoder Sites 部署能力、离线存储、BYOK 网络代理、浏览器兼容性。

必须比较：构建部署成本、许可、Markdown 导出保真、图谱可编辑性能、移动端与可访问性、长期维护性。记录被排除方案与原因。
