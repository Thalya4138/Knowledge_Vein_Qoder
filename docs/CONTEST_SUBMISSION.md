## 2. 作品帖模板

> **2026-11-26**：按站点现状写好的正文草稿在 [CONTEST_POST.md](CONTEST_POST.md)，发帖以它为准。
> 本节保留为写作要求；下面第 4、8 段的示例步骤与限制写于 11-11，已与站点现状不符（例如数据「可导出为 Markdown + JSON」目前只对导图与关联探索成立）。

标题：

```text
〖StudyHack〗知脉 Vein｜让已经学过的东西真正连起来
```

正文九段（**按这个顺序，不要写成产品说明书**）：

### 1. 自我介绍
学校、专业、年级、团队成员与分工。真实信息，不暴露隐私细节。

### 2. 一句话作品
> 把课程材料变成能读的讲义，再把讲义里的概念连成**每条都有理由**的知识网络，
> 而且这张网可以自己动手编辑。

### 3. 为什么做（**这一段决定初筛**）
写**具体的痛点**，不写行业趋势。可用的真实叙述方向：

- AI 摘要读起来顺，但下次想不起来——因为它没有接在我已知的地方
- AI 生成的思维导图节点很密，但边没有理由，不能用来回忆，也不能用来迁移
- 学完一章，题目换个问法就不会——因为不知道结论成立的条件

**要点**：不要写"随着 AI 技术的发展……"。写你上周具体卡在哪里。

### 4. 怎么用（5 步，配截图）
```text
① 打开示例课程「最小二乘与正交投影」
② 读一节讲义，展开一个折叠的推导，点标题旁的 § 复制锚点
③ 搜「法方程」→ 看到两处命中及各自上下文 → 点击跳转
④ 在关联探索里问「点到平面距离和最小二乘是一回事吗」→ 看到统一模型、完整证明、差异与边界
⑤ 把这条关系确认进图谱 → 切到个人记忆视图拖动节点 → 导出，再导入，一切还在
```

### 5. Qoder 开发过程（**这一段决定"Qoder 使用深度"得分**）
- 哪些部分交给 Qoder，哪些是我自己做的判断
- 遇到过什么具体错误、怎么定位、怎么改
- Qoder Sites 部署与迭代过程
- **附**：开发对话截图、提交记录、目录结构变化

**不要**贴一段"Qoder 很好用"的评价。贴过程。

### 6. 作品链接
真实、已验证、匿名可访问的 Qoder Sites URL。

### 7. 所用 Qoder 账号
准确填写。

### 8. 技术与限制（诚实加分，不扣分）
- 无 API Key 时的示例模式与真实功能的边界
- 数据存在浏览器 IndexedDB，可导出为 Markdown + JSON
- 尚未实现：语义检索、MATLAB/PyTorch 执行、Git 双向同步

### 9. 接下来
一段话说清楚下一步做什么，以及为什么现在没做（时间/依赖）。
