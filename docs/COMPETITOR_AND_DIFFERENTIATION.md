# 竞品与差异化

**这不是完整检索。** 只列已核验的公开页面，且会过期。
**禁止**基于"没搜到"宣称首创。

---

## 1. 外部已有能力（都别声称自己发明）

| 能力 | 已有实现 | 我们的关系 |
| --- | --- | --- |
| 双链笔记 / Canvas / 图谱 | Obsidian | 我们学它的"落盘 + 可迁移"，不做它的通用笔记 |
| 间隔重复 | Anki / RemNote | 我们只做"从关系生成练习"，不做完整 SRS |
| 程序化数学动画 | Manim / 3B1B | 我们调用，不重造 |
| PDF 对话 | ChatPDF 类 | 这是我们要**超越**的形态 |
| 自动思维导图 | 各类 AI 工具 | **这是我们要明确对立的形态** |

---

## 2. 差异化：不是"功能更多"，是"层级不同"

| 常见产品 | 它的假设 | 我们的假设 |
| --- | --- | --- |
| AI 摘要 | 学习 = 压缩信息 | 学习 = 把新信息接到已有结构上，压缩会毁掉接点 |
| 自动思维导图 | 知识 = 节点 + 连线 | 知识 = 节点 + **带走理由和条件的**连线 |
| 知识管理工具 | 组织 = 分类与检索 | 组织 = 同时维护**客观结构**与**个人记忆路径**两套视图 |
| 学习平台 | 路径 = 线性课程 | 路径 = 体系式与问题式可随时互换 |

**一句话差异**：
> 别人在帮你"记得更多"，我们在帮你"知道为什么连在一起，以及什么时候不该连"。

---

## 3. 本届相邻作品（2026-11-11 观察）

| 方向 | 风险 | 我们的应对 |
| --- | --- | --- |
| 算法/网络互动可视化 | "可视化"本身不新 | 实验必须回链讲义锚点，且有退化情形测试 |
| 基于问题的读物生成 | "生成讲义"不新 | 强调**持续维护**（版本、补丁、来源锚点） |
| 文献 / 科研工作台 | "证据链"不新 | 我们的证据是**课程材料的段落锚点**，不是论文引用 |
| 通用关系图工具 | "可拖动图"不新 | 强调**三种视图语义不同**且**个人视图 AI 不得重排** |

---

## 4. 怎么验证我们真的不一样

选 5 个真实问题（不是 demo 脚本），跑：

| 检验 | 通过标准 |
| --- | --- |
| 读完一节，两天后能否复述"这节解决什么问题" | 3/5 以上能 |
| 给一个变式题，能否判断"能不能用这个结论" | 能说出条件 |
| 一条关系，能否指出"什么时候不成立" | 能指着 `assumptions`/`boundary` 说出来 |
| 换一个工具（纯 Markdown + 编辑器），知识库还能用吗 | 能 |
| 关掉 AI，核心流程还能走吗 | 能 |

**这些指标不写进比赛帖子当"研究结论"**，只作为内部取舍依据。
