## 2. 讲义质量（人工 + 抽查）

从 demo 中随机抽 1 节，**不看原文**回答：

- [ ] 这节解决什么问题？
- [ ] 关键结论凭什么成立？
- [ ] 什么条件下不成立？
- [ ] 能否在讲义中找到对应的来源锚点？

四项全对才算通过。任何一项答不出 = 不合格（不是"可改进"）。

再检查：

- [ ] 核心定义、关键推导步骤**不在** `<details>` 里
- [ ] 至少有一个 `caveat` 或 `correction` 块（说明失效情形）
- [ ] 有冲突材料时并列呈现，未擅自选边
- [ ] 无「本页重点」「综上所述」「这非常重要」类空转句

## 2.5 阅读器 · 资源抽屉（规格见 `UX_AND_FLOWS.md` §3"资源抽屉"，决策见 ADR-0007）

并排截图只能验"长什么样"，抽屉是关着的——**交互项必须逐条点过**，证据是 `?open=<spanId>` 的抽屉打开态截图，
外加下面每一项的手测记录（按 §10 模板）。

- [ ] 点旁栏资源卡：从**左侧**打开抽屉；主栏路由与滚动位置不变（不跳出讲义页）
- [ ] 抽屉五项齐全：类型、标题与许可、定位、原文片段（高亮）、why；改 `manifest.json` 里一条 span 的 `why`，刷新后抽屉随之变化（证明不是写死在组件里）
- [ ] PDF 资源：抽屉内嵌预览，并停在 span 指定的页
- [ ] 视频资源：抽屉内**没有**播放器，只有逐句时间戳引文；"从 mm:ss 开始播放"打开后确实从该时间开始
- [ ] 网页资源："打开并高亮这句话"在新标签打开，浏览器滚动到并高亮对应句子
- [ ] 把一条 span 的定位改为 `unavailable`：抽屉显示"位置待核对"，不出现只到资源主页的链接
- [ ] ×、点遮罩、`Esc` 都能关闭；关闭后焦点回到原卡片；连点两张卡片，抽屉内容替换而非叠层
- [ ] 资源抽屉（左）与 AI 侧栏（右）同时打开，互不遮挡；窄屏下后开的一方覆盖先开的一方，关闭后恢复
- [ ] 375px 宽：内联资源卡点击后抽屉全屏打开，且可关闭

## 3. 检索

- [ ] 搜一个术语，返回**多个位置**并说明各自上下文差异
- [ ] 点击结果能跳到真实段落（不是 404、不是顶部）
- [ ] 搜一个不存在的词，明确显示"未找到"，不编造章节
- [ ] "补入笔记"是可预览 diff，可取消，用户正文未被静默覆盖

---

## 4. 图谱

- [ ] 三视图切换：布局各自保留，节点 id 一致
- [ ] 拖动节点 → 刷新 → 位置还在
- [ ] **知识关系**连线：`explanation` / `assumptions` 为空时不允许进入 accepted（ADR-0003 不变）
- [ ] **手绘边**（`PersonalEdge`，ADR-0006）：`label` 空则不允许保存，`meaning` 空**允许**保存；
      它显示为虚线 +「我的联想」，与知识关系一眼可分；切到结构/逻辑视图后它不出现；
      报告的引用列表里选不到它
- [ ] 点一条边，能看到类型 + explanation + assumptions + boundary + 来源锚点
- [ ] AI 提议显示为幽灵层，**未点应用前不改变任何位置**
- [ ] 拒绝一条候选边，它能被标记为 rejected 且不进入结构视图
- [ ] 撤销/重做覆盖 拖拽、连线、分组

---

## 5. 图谱质量（内容标准）

- [ ] 没有一条 `related` 类型的边（该类型在 schema 里被禁止）
- [ ] 每条 accepted 边都能回答"凭什么"和"何时失效"
- [ ] 至少一条 `analogy` 边在 UI 上明显区别于 `source-backed`（线型 + 标签）
- [ ] 多前提推导用 `RelationGroup`，未压成两条二元边

---

## 6. 可视化

- [ ] 参数改变真的改变数学输出（不是预渲染视频假装的）
- [ ] 界面上能看出这条运行是 `real` / `pre-rendered` / `example` / `failed`
- [ ] 有退化情形测试（如 A 两列相同）且行为正确
- [ ] 实验能回链到讲义锚点

---

## 7. 无 Key 与容错

- [ ] 断网后：已加载的讲义仍可读，编辑仍可保存
- [ ] 无 Key 时：搜索、编辑、图谱、导入导出真实可用
- [ ] 示例结果有明显标注，不冒充实时生成
- [ ] AI 调用失败：不白屏、不丢用户输入、给出重试

## 8. 体验与性能

- [ ] 首屏 30 秒内能找到"打开示例课程"
- [ ] 演示路径 ≤5 步走完
- [ ] 手机宽度（375px）不横向滚动
- [ ] 控制台无致命错误；所有首屏按钮都有动作（无死链、无 `href="#"`）
- [ ] 图谱拖拽在 demo 全部节点下无卡顿（规模以 `content/demo/linear-algebra/graph.json` 为准，别在文档里写死数字）
- [ ] 首屏显示的统计数字来自运行时计算，与已加载数据一致
