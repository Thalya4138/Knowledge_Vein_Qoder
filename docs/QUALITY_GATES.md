# 验收标准 · 能跑、能读、能信、能恢复

验收分为确定性测试、真实内容测试、交互/视觉测试和比赛部署测试。测试结果须标记日期与证据；不能写“通过”但未运行。

## 1. 知识与讲义保真

- 同一份课程资源生成的讲义包含原课程关键概念、论证逻辑、必要例题，不因“压缩摘要”丢掉前提和结论。
- 语言是可连续阅读的教材式叙述，标题层级有意义，不每句话单独列一条。
- 原始材料、准确转述、补充解释、个人理解、类比、猜测分开。
- 至少 5 个抽查事实和 3 个推导链可溯源；未提供来源时明确“无来源/需核对”。
- 折叠练习/补充不折叠核心定义和必需论证；不出现一屏 100 个无意义标签。
- 同一份笔记导出 Markdown 后脱离网站仍可读、可编辑、公式可渲染。

## 2. 资源与检索

- 资源侧栏能区分用户导入与系统发现、许可与可信度；不能暗中使用未经授权的付费文本。
- 搜索“法方程”正确列出相关讲义/来源片段，点击可定位，不返回不存在章节。
- 同一术语多处出现时列出多个位置、解释各自上下文；没有结果明确告知。
- AI 一键补充是可预览 diff，有取消和撤销；用户编辑的正文不被静默替换。

## 3. 知识关系

- 每条 accepted 关系至少有类型、自然语言说明、条件或适用范围、证据/逻辑依据；类比和猜想使用不同标识。
- 数学回归：AᵀA 可逆 iff A 满列秩（实数情形）；不能无条件断言法方程解唯一。
- 可测试“关系相似但不等价”样例，系统应明确差异而非强行同构。
- 复合前提命题不能因二元图的简化失去逻辑条件。
- AI 提议的边只在用户确认之后入库，拒绝与修改可追踪。

## 4. 三视图与记忆

- 结构/逻辑/个人记忆三个视图独立修改布局；刷新和导出/导入后布局保持。
- 节点/边手动创建、编辑、删除、拖动；撤销/重做与键盘基本操作。
- 个人记忆路径允许用户自定义次序、分组和含义；AI 不自动重排个人布局。
- 记忆状态显示为基于何种练习或用户自评，不把打开文档等同于掌握。

## 5. 可视化与工具

- 实验的参数改变真实数学输出，结果可重复；有极端值和退化条件测试。
- API 无 Key/超时/不支持浏览器时，真实功能继续可用并给清楚反馈。
- 外部工具执行状态显示真实/预置/失败，不伪造执行记录。
- 模型生成代码不能未经授权在服务器或本机执行。

## 6. 工程、隐私和体验

- 第一次访问 30 秒内找到示例；演示路径不超过 5 步。
- 编辑/刷新/断网/恢复/导出再导入后无静默数据丢失。
- 访问手机宽度不重叠；键盘焦点、对比度、公式和 Markdown 可读。
- 性能：示例规模图谱拖拽流畅；资源检索和导航有合理加载反馈。
- 浏览器控制台无致命异常；应用不白屏；所有首屏按钮有动作。
- .env/key/私人课程 PDF 不上传公开 GitHub；用户看得到数据保存在哪里。

## 7. 比赛专项验收

- Qoder Sites 公开 URL 无登录可访问，手机/桌面亲自测试；
- Qoder 真实开发与部署过程有截图或任务记录；
- 赛题页论坛标题带 〖StudyHack〗，包含自我介绍、一句话作品、起因、5 步内使用、Qoder 过程、Qoder 账号、链接；
- 时间在 2026-11-30 18:00（北京时间）之前；赛前实名认证/阿里云大学生认证按官方要求完成；
- 奖项/评委评价不在提交前保证。

## 8. 记录模板

日期｜版本/提交｜测试环境｜测试用例｜预期｜实际｜证据路径｜结论/未修复问题。
