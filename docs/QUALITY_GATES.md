# 验收标准

**判据来源**：讲义质量 ← `prompts/NOTE_GENERATION.md` §7；关系质量 ← `docs/DOMAIN_MODEL.md` §3；
竞赛 ← `docs/CONTEST_SUBMISSION.md`。

**每一条都必须能被一条命令或一次点击验证。** 无法验证的条款不写在这里。

---

## 1. 自动化验收（CI 必须跑）

```bash
npm run verify:content   # 样例数据 + 引用完整性 + 讲义链接 + 提纲化检测
npm run typecheck
npm run test             # 单元：领域校验、导出保真、检索锚点
npm run build
```

| ID | 条款 | 验证方式 |
| --- | --- | --- |
| A1 | 每条关系有 `explanation` ≥12 字、`assumptions` ≥1 项、`epistemic` 合法 | `verify:content` |
| A2 | 关系的 `from`/`to` 均指向存在的节点 | `verify:content` |
| A3 | `analogy` / `hypothesis` 必带 `boundaryOrCounterexample` | `verify:content` |
| A4 | 声称 `source-backed` 必带 `evidenceIds` | `verify:content` |
| A5 | 讲义 `[[wiki link]]` 能解析到节点或章节 | `verify:content` |
| A6 | 讲义列表密度不超标（防提纲化） | `verify:content` |
| A7 | 导出→清库→导入后：节点数、关系类型分布、三布局坐标、MemoryCue、Markdown hash 一致 | `test` |
| A8 | `AᵀA` 可逆 ⇔ `A` 满列秩（实数域），含反例：单行矩阵 `[1 1]` | `test` |
| A9 | 检索命中返回的锚点在文档中真实存在 | `test` |

## 2. 讲义质量（人工 + 抽查）

从 demo 中随机抽 1 节，**不看原文**回答：

- [ ] 这节解决什么问题？
- [ ] 关键结论凭什么成立？
- [ ] 什么条件下不成立？
- [ ] 能否在讲义中找到对应的来源锚点？

四项全对才算通过。任何一项答不出 = 不合格（不是"可改进"）。

再检查：

- [ ] 核心定义、关键推导步骤**不在** `<details>` 里
- [ ] 至少有一个 `caveat` 或 `correction` 块（说明失效情形）
- [ ] 有冲突材料时并列呈现，未擅自选边
- [ ] 无「本页重点」「综上所述」「这非常重要」类空转句

---

## 3. 检索

- [ ] 搜一个术语，返回**多个位置**并说明各自上下文差异
- [ ] 点击结果能跳到真实段落（不是 404、不是顶部）
- [ ] 搜一个不存在的词，明确显示"未找到"，不编造章节
- [ ] "补入笔记"是可预览 diff，可取消，用户正文未被静默覆盖

---

## 4. 图谱

- [ ] 三视图切换：布局各自保留，节点 id 一致
- [ ] 拖动节点 → 刷新 → 位置还在
- [ ] 手动连线必须填"意味着什么"，空内容不允许保存
- [ ] 点一条边，能看到类型 + explanation + assumptions + boundary + 来源锚点
- [ ] AI 提议显示为幽灵层，**未点应用前不改变任何位置**
- [ ] 拒绝一条候选边，它能被标记为 rejected 且不进入结构视图
- [ ] 撤销/重做覆盖 拖拽、连线、分组

---

## 5. 图谱质量（内容标准）

- [ ] 没有一条 `related` 类型的边（该类型在 schema 里被禁止）
- [ ] 每条 accepted 边都能回答"凭什么"和"何时失效"
- [ ] 至少一条 `analogy` 边在 UI 上明显区别于 `source-backed`（线型 + 标签）
- [ ] 多前提推导用 `RelationGroup`，未压成两条二元边

---

## 6. 可视化

- [ ] 参数改变真的改变数学输出（不是预渲染视频假装的）
- [ ] 界面上能看出这条运行是 `real` / `pre-rendered` / `example` / `failed`
- [ ] 有退化情形测试（如 A 两列相同）且行为正确
- [ ] 实验能回链到讲义锚点

---

## 7. 无 Key 与容错

- [ ] 断网后：已加载的讲义仍可读，编辑仍可保存
- [ ] 无 Key 时：搜索、编辑、图谱、导入导出真实可用
- [ ] 示例结果有明显标注，不冒充实时生成
- [ ] AI 调用失败：不白屏、不丢用户输入、给出重试

---

## 8. 体验与性能

- [ ] 首屏 30 秒内能找到"打开示例课程"
- [ ] 演示路径 ≤5 步走完
- [ ] 手机宽度（375px）不横向滚动
- [ ] 控制台无致命错误；所有首屏按钮都有动作（无死链、无 `href="#"`）
- [ ] 图谱拖拽在示例规模（9 节点）下无卡顿
