# 视觉系统与页面层级（DESIGN）

**本文件是界面视觉的真源。** 写任何界面之前先读它；样式只引用 `apps/web/src/styles/tokens.css` 的变量，
不在页面里另起颜色、字号、阴影、圆角。

依据：`VISION.md` 第三部分 2026-11-15 用户原话（Apple 式的美感、封面式首页、页面格局重构），
用户审美画像（蓝、银、清新、有构图、简洁但不无聊；拒绝土奢、廉价广告感、堆渐变、俗气字体），
以及两套设计规范的原文：Anthropic `frontend-design` 与 Nutlope `Hallmark`（本机已安装，不进仓库）。

---

## 1. 一句话主张

> **银色的纸面上，知识沿着叶脉生长。**
> 界面像一件精密的器物：退到内容后面，只在你伸手时回应。唯一大胆的地方是封面那张知识地形图。

「Apple 的美感」在这里落成四条可检查的规则，而不是模仿苹果官网的样子：

1. **内容是主角，界面退后。** 导航与工具栏是半透明的薄层（`backdrop-filter`），不画框、不抢色。
2. **层次靠字号、字重与留白，不靠框。** 一屏之内最多三档字号；同一层级的东西长得一模一样，不同层级差得足够远。
3. **深度靠材质，不靠描边。** 浮在上面的东西（AI 对话框、弹出层）用柔和的大阴影与半透明背景；平面上的东西不加阴影。
4. **动效是回应，不是表演。** 只在用户动手时动：打开、展开、切换页面。页面切换用连续的过渡（View Transitions），不用每块内容依次淡入。

## 2. 明确拒绝的「AI 味」

以下每一条都是上一版界面实际犯过的，或两份设计规范点名的生成式默认值。**新代码不得出现**：

- 暖奶油色底（`#F4F1EA` 一带）、近黑底配一个荧光色、紫到蓝的渐变；
- 每个标题上方挂一个小标签（eyebrow），大写字母加字距的标签；
- 内容并不是先后顺序却加 01 / 02 / 03 编号；
- 用中点连接的元信息（「A · B · C」），链接文字后面粘一个「→」，装饰性的状态圆点；
- 一模一样的圆角卡片排成一排、每张卡片同样的阴影、卡片套卡片；
- 硬朗的偏移阴影（`3px 3px 0`）——那是复古印刷风格，不是本产品的材质；
- 解释「这个页面是干什么的」的说明文字。**未实现的功能**允许留一句占位，说明它将做什么。

## 3. 页面层级与导航

```text
封面 /                         大字标 + 一句话 + 四个工作空间入口；背后是生成的知识地形图
 ├─ 学习工作台 /workspace       应用界面：工作区栏 | 文件栏 | 文件内容，AI 对话框悬浮
 ├─ 可视化实验室 /lab            深色界面：对话气泡起手，返回多种可视化窗口
 ├─ 关联探索 /connection         对话界面：碎片串联 / 学科元思考 / 跨学科并联
 └─ 认知记忆图谱 /atlas        选工作区 → 选图谱（思维导图 / 个人记忆图谱）→ 画布，AI 对话框悬浮
```

**抉择：板块之间进入新页面，板块内部原地切换。**

- 封面到板块：**进入新页面**（与用户个人站一致）。四个板块是四种完全不同的工作方式（读文件、看可视化、对话、编辑画布），
  它们的界面密度和配色都不同，放在同一个页面里切 tab 只会让两边都将就。
- 板块内部：**原地切换**。在工作台里换文件、在图谱里换视图、在关联探索里换模式，都不离开当前页面，
  因为用户手上有正在进行的东西（打开的文件、画布状态、对话），离开就会丢失上下文。
- 图谱的「选工作区 → 选图谱」是唯一的逐级进入：它们是**选择**，不是工作；选完才进入画布。
- 状态写进地址（`?file=`、`?mode=`、`?map=`），刷新和分享都能回到原处。

页眉：所有页面共用一条细的半透明顶栏。左边是字标（回封面），中间是四个板块，右边留给工作区与设置。
实验室页面的顶栏切换为深色。

## 4. 颜色

银白为底，墨蓝为字，**只有一个强调色**。颜色只当信号用：当前选中、主操作、焦点、连线高亮。

| 变量 | 值 | 用途 |
| --- | --- | --- |
| `--bg` | `#f4f5f7` | 页面底色，冷调的银白，不用暖奶油色 |
| `--surface` | `#ffffff` | 浮在底色上的面（文件内容区、对话框） |
| `--glass` | `rgb(255 255 255 / 0.72)` + `blur(20px)` | 顶栏、侧栏、悬浮框的半透明材质 |
| `--ink` | `#0e1726` | 正文与标题 |
| `--ink-2` | `#475266` | 次级文字 |
| `--ink-3` | `#667085` | 说明、时间、计数（对 `--bg` 对比度 ≥ 4.5） |
| `--hairline` | `rgb(14 23 38 / 0.10)` | 唯一的分隔线 |
| `--accent` | `#2456d3` | 「脉」的蓝：主操作、选中、焦点、连线高亮 |
| `--silver` | `#c9ced8` | 未高亮的连线、节点、禁用 |

实验室（深色）：`--lab-bg #0a0e16`、`--lab-surface #121826`、`--lab-ink #e8ecf3`，强调色提亮为 `#6f9bff`。
深色是**真正的深蓝黑**，不是纯黑加荧光。

## 5. 字体

| 角色 | 字体 | 说明 |
| --- | --- | --- |
| 字标「知脉」 | Noto Serif SC Black，转成 SVG 路径 | 唯一的衬线，唯一的「艺术」。不加载字体文件 |
| 字标「Vein」 | Computer Modern Italic（KaTeX 自带），转成 SVG 路径 | 数学教科书的斜体，给一点学术气质 |
| 大标题 | Noto Sans SC，**只截取页面上固定出现的字**，自托管 woff2 | 让 Windows 上的大标题也干净；字距收紧 −0.02em |
| 正文与界面 | 系统字体：苹方 / HarmonyOS Sans / 微软雅黑 | 内容是动态的，中文全字库太大，无法自托管 |

字号阶梯（px）：`13 · 15 · 17 · 22 · 32 · 56 · 96`。正文 15–17，界面 13–15，板块标题 32–56，封面 96。
字重只用两档：400 与 600（大标题 700）。

> 系统字体与 Noto Sans SC 都在 Hallmark 的「默认字体」名单上。这里有意使用：中文网页不能自托管全字库，
> 系统字体是唯一可行的正文选择；个性交给字标承担。

## 6. 形状、材质、动效

- **圆角**：外层容器 20px，里面的元素按「外圆角 − 内边距」同心递减（14 / 10 / 6）。按钮是胶囊形。
- **阴影只有一种**，只给浮起来的东西：`0 12px 40px rgb(14 23 38 / 0.10), 0 2px 6px rgb(14 23 38 / 0.06)`。
- **分隔**：留白优先，其次一条 `--hairline`，再次一块浅底色。不用边框围住内容。
- **动效**：时长 120 / 220 / 420ms，缓动 `cubic-bezier(0.2, 0.8, 0.2, 1)`；只动 `transform` 与 `opacity`。
  封面「脉」的生长是全站唯一一次编排好的动画；其余只回应操作。`prefers-reduced-motion` 时全部关闭。

## 7. 响应式

`≥ 1100` 完整；`720–1099` 工作台文件栏默认收起；`< 720` 单栏，侧栏变抽屉，AI 对话框贴底全宽。
每次交付截图至少 1440 / 1024 / 390 三个宽度。

## 8. 各板块的界面（落地顺序见 `IMPLEMENTATION_PLAN.md` §R）

- **学习工作台**：像 Obsidian / GitHub。左一栏是工作区（学科），左二栏是当前工作区的文件树，两栏都能收起；
  主区显示打开的文件（HTML 内嵌、PDF、Markdown、图片），可阅读、可编辑、可高亮；AI 对话框悬浮在底部中央，
  可以维护工作区、补笔记，也可以问一个知识点，下拉出多处定位结果，点开定位并短暂高亮；对话历史可查。
- **可视化实验室**：深色。起手是一个对话气泡「你想看见什么？」，输入后返回几个可视化窗口，逐个点开。
- **关联探索**：对话界面，三个模式（碎片串联 / 学科元思考 / 跨学科并联）只改变给模型的约束，界面相同。
  回答旁边同时生成一张可拖动、可编辑的关联图；回答与图都能原样复制、拖进笔记或图谱、导出为文件。
- **认知记忆图谱**：选工作区 → 选图谱 → 画布。思维导图横向分层、纵向逻辑，连线上只写必要的一句人话；
  个人记忆图谱以思维导图为本源，可以收起、遮盖、挖空自测（快捷键一键对照原文）、自由摆放（「自动对齐」开关）。

## 9. 封面：知识的地形图（2026-11-16，用户指定参照 Hallmark 的 Furrow / Cobalt 主题）

用户认为上一版封面的连线图「不大美观」，指定参照 Hallmark 的 Furrow 与 Cobalt 主题，**只取封面的美工与动态**。
两者的共同手法是：首屏背景由程序实时生成，画的是产品自己的世界。本产品取 Furrow 的路线，并换成自己的材质：

- 等高线由固定种子的噪声加「概念即山峰」生成（canvas，不是图片），核心概念更高；配色用本系统的银与墨蓝，不用牛皮纸色；
- 结构图谱里的九个概念钉在峰上，图钉形状区分概念 / 定理 / 方法 / 例子；课程主线是一条虚线路径；
- 笔记卡片给出一条连线的理由与成立条件，‹ › 翻看；放大镜跟随指针，静止时停在当前连线的终点；
- 动效只在载入时编排一次：地形淡入、图钉依次落下、路径画出、卡片打开；减少动态时全部直接显示终态；
- 首屏左侧的四个入口取代了原来的两个按钮，封面因此是一屏，不再有下方的入口卡片。

工作台的两个侧栏各自带收起按钮，收起后留 40px 细边，点击即展开（用户 2026-11-16：「左一左二侧栏可以分别收起」）。

## 10. 白天与夜间（2026-11-16）

- 同一组变量两套值：`:root` 是白天，`:root[data-theme='dark']` 是夜间（`styles/tokens.css`）。页面里不写任何只属于某一种模式的颜色。
- 夜间是深蓝黑（`#0b1018`）而不是纯黑；强调色提亮为 `#7aa2ff`；阴影加深。
- 默认跟随系统；页眉的月亮 / 太阳一键切换，设置里可选白天、夜间、跟随系统。首屏渲染前就读取偏好，避免闪烁。
- 封面地形图与图谱卡片里的小地形，在切换时按新的变量重画。
- **实验室不再固定为深色**（用户：「科幻一点不意味着背景就莫名其妙变成了黑色」）：它跟随主题；科幻感来自透视坐标地面与轨道线，两种模式下都成立。
- 讲义样张是「纸」，夜间仍保持白纸，不反色。

## 11. 配色与按钮（2026-11-16 第五轮，取代 §4 的色值）

用户：「页面的 AI 感还来自于配色的过于经典 AI」。银白底加科技蓝正是生成式页面最常见的组合，改为：

| 变量 | 白天 | 夜间 | 来历 |
| --- | --- | --- | --- |
| `--bg` | `#edf0ea` 浅灰绿的纸 | `#11181c` | 清新、不刺眼，避开暖奶油与纯白 |
| `--accent` | `#1f4e79` 普鲁士蓝 | `#8fb6dc` | 用户偏好的蓝，但用沉稳的颜料蓝，不用科技蓝 |
| `--cinnabar` | `#b53c0b` 朱砂 | `#f08a5d` | 「朱批」：老师批改的红笔。只用于当前步骤、高亮、提醒 |

**按钮改为键帽**（用户：「做成按键那样……有边框，但又不是 AI 感很重的细细的线条边框」，参照用户个人站）：
2px 墨色边框、9px 圆角、底部一道 3px 实边，悬停上浮 1px，按下时下沉、实边消失。页眉导航、页眉右侧、封面四个入口、实验室工具共用 `.key`。

封面放大镜（用户：「圆圈还是要跟随鼠标……不能到了左半边还跟随」）：只在地图区域（宽度 46% 以右、且不在卡片上）跟随指针，其余时候停在当前一步的结论上。
封面图钉按卡片的实际位置排布：主路线放在「卡片上沿以上」的带里，应用放在卡片左边；窄屏放不下时隐去一个应用，不让任何图钉落进卡片。

## 12. 思维导图（2026-11-19）

用户对上一版的评价是「太 AI、太死板、太冰冷」，并给了两张参考界面（粗墨边面板、点阵画板、牌式块与贴在上沿的小角标），
要求与本站风格结合，并且能像 WPS 思维导图一样继续编辑、内置 LaTeX。落地为 `features/atlas/MindEditor.tsx`：

- **骨架**：工具条 / 大纲 | 画板 | 详情 / 底栏。面板与画板用 2px 墨边加底部 4px 实边，与键帽（§11）同一语言；画板是点阵纸。
- **节点是牌，越靠近根越重**：根是深色键帽；第一层是带分区底色的键帽；第二层是白牌加底边；第三层是细边浅牌；更深只留文字与下划线。
- **分区色只有三种**（`--band-0/1/2` 与对应的连线色），表达「这一支属于哪一区」，不是每个分支一种颜色。
- **角标贴在牌的上沿**：朱色实底是用户写的角标（如「补 本构关系」）；朱色描边是「前提 n」，由知识关系的前提现算；蓝色描边是关联数。
- **两类连线一眼可分**：知识关系用蓝线，线型按认知状态（有出处为粗实线、可推导为实线、教学归纳为虚线、类比与待验证为点线），文字等级在详情栏；
  我的连线用朱色双线，标签前写「我的」。默认只在选中主题时显示，避免满屏交叉。
- **底栏随状态换提示**：选中、编辑、画连线时显示不同的按键。快捷键表（F1）里放导入导出。
- **字体**：节点用阅读字体（霞鹜文楷子集，未覆盖的字回退到系统字体），公式用 KaTeX，界面用系统字体。
- **个人记忆图谱**与思维导图同一语言：键帽工具条、点阵画板、牌式节点与分区色。挖空是蓝色虚线框；对照原文时答对标蓝色「对」，答错用朱笔划掉自己写的答案（「朱批」）。右上角计分牌只数事实：已填、挖空、答对几处。

## 13. 讲义版式（2026-11-24，以验收样张为准）

**真源**：版式以 `content/demo/linear-algebra/rendered/`（用户认可的验收样张）为准，语言以人教版《生物学 必修2》为准（本地《参照教材学习.pdf》，私人材料，不进仓库；规则见 `TEXTBOOK_STYLE_ANALYSIS.md`、`prompts/NOTE_GENERATION.md` §3.5、§6.5）。
阅读器（`reader/NoteReader.tsx` + `styles/reader.css`）、关联探索的回答、导出到讲义的内容都按这一份渲染；**改阅读器前先把同一篇讲义在样张和阅读器里各截一张对比**。

**规范，不是模板**（用户 2026-11-24 晚）。本节规定的是：一个栏目、一张表、一条旁注**用到的时候长什么样**。它不规定一篇文章必须有哪些栏目、按什么顺序排。讲义有讲义的教学结构（问题探讨、本节聚焦、练习与应用）；关联探索的回答是另一种文体，结构由那一次的内容决定，可以一个教学栏目都不用。示例工作区的三篇关联探索（`content/demo/linear-algebra/explore/`）同理：它们示范的是讲得多透、例子多具体，不是可以照填的骨架。把示例的节名与栏目顺序当模板去套，视为缺陷（`prompts/CONNECTION_EXPLORER.md` §3）。
