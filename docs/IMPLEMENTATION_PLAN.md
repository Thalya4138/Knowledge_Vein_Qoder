### 5.4 各功能的逐步实现路线（2026-11-16，用户要求写清「怎么逐步实现」）

### 5.5 公网部署（按比赛要求）

**「公网」具体指什么**（2026-11-16 查证，来源是其他参赛作品的公开仓库，非官方文件）：
Qoder Sites 给每个站点一个 `<项目名>-<随机串>.qoder.zone` 或 `.qoder.website` 的地址，例如
[前程指北](https://github.com/zcf2230/qiancheng-zhibei)、[读完](https://github.com/cwdghh/finish-reading)、[学涯助手](https://github.com/angelky7/study-helper)。
