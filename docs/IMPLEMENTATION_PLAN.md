## 2. 任务分解（按依赖顺序，不按板块）

每个任务都是**可独立验收**的。做完一个再开下一个。

### T0 · 地基（必须先做）

- **T0-1** 脚手架：Vite + React + TS，四区路由，错误边界，状态条
- **T0-2** ADR-0002：选型 + Qoder Sites 能力验证结果
- **T0-3** domain 层：`content/demo/*.json` 对应的 TS 类型 + zod 校验
- **T0-4** 数据加载：构建时读取 `content/demo`，或运行时 fetch

### T1 · 阅读（产品门面）

- **T1-1** Markdown 解析器：标题锚点、`::: block`、`<details>`、`[[wiki link]]`、KaTeX
- **T1-2** 阅读器 UI：目录、正文排版、块样式、折叠
- **T1-3** 锚点跳转与复制

### T2 · 检索

- **T2-1** 确定性检索：标题/正文/别名/锚点，按位置分组返回
- **T2-2** 结果面板：多命中 + 上下文差异 + 点击跳转
- **T2-3** 补入 diff：预览、确认、撤销

### T3 · 图谱

- **T3-1** 图谱渲染：节点（按 importance 分大小）、边（按 epistemic 分线型）
- **T3-2** 三视图切换 + 布局持久化（IndexedDB）
- **T3-3** 手工编辑：拖动、连线（必填含义）、分组、撤销/重做
- **T3-4** 边详情面板：类型/解释/条件/边界/来源
- **T3-5** 候选边：幽灵层渲染 + 接受/拒绝

### T4 · 关联

- **T4-1** A 模式 UI：输入多项 → 对应表 → 统一句 → 差异 → 候选
- **T4-2** 无 Key 时的预置示例（明确标注）
- **T4-3** BYOK 接入（若 Qoder Sites 允许）

### T5 · 实验

- **T5-1** 正交投影交互：拖动 b、改变 A、显示残差与正交
- **T5-2** 退化情形（A 列相关）
- **T5-3** 回链讲义锚点

### T6 · 持久化与导出

- **T6-1** IndexedDB schema + 自动保存 + 保存状态提示
- **T6-2** 导出 ZIP（md + json + assets）
- **T6-3** 导入 + 校验 + 冲突提示
- **T6-4** 导出→导入保真测试

### T7 · 交付

- **T7-1** Qoder Sites 部署
- **T7-2** 录屏 + 截图清单
- **T7-3** 天池帖子
