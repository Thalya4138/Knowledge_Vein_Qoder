# 优质课程笔记样本分析（内部方法提炼）

参考输入：用户提供的《2026-10-28第10-11节 详细笔记.pdf》，30 页，题为《先秦诸子：名家与孟子》，标识“积木笔记”。**样本属于用户提供的第三方材料，不应未经授权进入公开 Git 仓库或公网 Demo。** 本文只抽象其表达与结构方法，不复制正文。

## 为什么它是“人读得懂”的笔记

1. **从课程内部逻辑开始**：先交代上一讲框架与本讲材料的接续关系，随后按辩论/论证的递进展开，不从工具处理视角写“本页重点”。
2. **有完整的语义段落**：段落先说明问题，再引材料、解释关键语句、追踪推理及回应，不把每句拆成一条只有标题的 bullet。
3. **文献材料与解释分层**：原文/引用在“材料”框内，出处明确；解释自然穿插在材料之后；“注”“补充”“观点”分别承担术语、逻辑辨析、多个解释可能。
4. **保留概念边界和论证局限**：对白马非马，明确区分“不相等”与“不属于”；对孟子反驳告子，区分推翻对方论证方式与正面证明自己命题。没有为了顺滑而抹平不确定性。
5. **用表格处理真正需要对照的结构**：如“常/变/变的缘故”的多项比较；不随意把所有段落变为表格。
6. **理解脉络与课堂主线并存**：包括推理手法、历史背景、词义注释、争论双方的推进。这些不是纯“考试重点”，而是学习所需的语境。
7. **总结靠后且克制**：主体先完整讲清，最后用小结帮助检索与复盘，摘要没有取代正文。

## 转成产品规范

- 正文 = 可以独立阅读的讲义；表格/材料/定义/辨析用分层块体现；小结用于回看，不是主要内容。
- 课程原始主干与解释/补充并存，自动折叠的适合是习题、拓展争论、冗长证明变体，不得把必要论证默认折起来。
- 来源可定位：原资源的段落/页/时间戳，正文解释与原文区分。
- 原文材料不只“复制出来”，要解释其论证角色；科学课程则对应定义、定理、推导、实验设计、误差与反例。
- 同样的写作方法跨学科适配，而不强行套古典文献的“材料 x”编号。

## 样本启发的一条验收用例

输入一节讲义和课堂材料：
- 预期：能读出该节从何而来、要解决什么、关键概念、论证前提、推导步骤、哪些问题尚有争议。
- 失败：只有十几个标题/关键词；用漂亮框架替代解释；把不可靠的类比写成定理；没有材料出处；缩写到失去课程知识。
- 人工盲测：读者不看原资源能否正确解释两个关键概念和至少一条推理链？能否在原资源中找到相应内容？

将这些检查直接映射到 prompts/NOTE_GENERATION.md 的生成、批评与修订流程。
